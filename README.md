# بوت تسجيلات القرآن لجدتك 🌙

بوت تليجرام: تبعتيله اسم السورة ورقم الآيات، يختار المستخدم القارئ وعدد التكرار،
ويرجعلها تسجيل صوتي (mp3) جاهز للمشاركة على واتساب.

---

## الخطوة 1: اعملي بوت على تليجرام (5 دقايق)

1. افتحي تليجرام وابحثي عن حساب اسمه **BotFather** (فيه علامة ✔️ زرقاء).
2. ابعتيله الأمر: `/newbot`
3. بيطلب منك اسم للبوت (أي اسم، مثلاً "بوت القرآن").
4. بيطلب منك username لازم ينتهي بـ `bot`، مثلاً `grandma_quran_bot`.
5. بيرجعلك رسالة فيها **توكن** (token) شكله شبيه بـ:
   `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   خليه سري وما تشاركيه مع حدا.

---

## الخطوة 2: شغّلي البوت

### خيار أ) على جهازك (أسهل للتجربة)

يتطلب: بايثون 3.10+ و ffmpeg مثبتين على جهازك.

```bash
# 1. ثبتي ffmpeg (لازم لدمج الملفات الصوتية)
# على ماك:
brew install ffmpeg
# على أوبنتو/لينكس:
sudo apt install ffmpeg
# على ويندوز: حملي من ffmpeg.org وضيفيه لـ PATH

# 2. ثبتي المكتبات
cd quran_bot
pip install -r requirements.txt

# 3. شغلي البوت (حطي التوكن يلي أخذتيه من BotFather)
export BOT_TOKEN="التوكن_تبعك_هون"
python3 bot.py
```

طول ما هالبرنامج شغال على جهازك، البوت رح يشتغل. لو سكرتي الطرفية (terminal) أو الجهاز، البوت بده يوقف.

### خيار ب) استضافة مجانية دائمة (Railway.app) — موصى فيها

1. اعملي حساب على [railway.app](https://railway.app) (فيه فيها مجاني بحدود شهرية كافية لبوت صغير).
2. ارفعي مجلد `quran_bot` كـ repo على GitHub (أو استخدمي Railway CLI لرفعه مباشرة).
3. من Railway: New Project → Deploy from GitHub repo → اختاري الـ repo.
4. Railway رح يحتاج ffmpeg — ضيفي ملف اسمه `nixpacks.toml` بهالمحتوى بجانب bot.py:
   ```toml
   [phases.setup]
   nixPkgs = ["ffmpeg"]
   ```
5. من إعدادات المشروع (Variables) ضيفي متغير:
   `BOT_TOKEN` = التوكن تبعك.
6. Railway بيشغل تلقائياً: `python3 bot.py` (لو ما اشتغل، حددي Start Command يدوياً بهالأمر).

بعد الرفع، البوت رح يضل شغال 24 ساعة بدون ما يحتاج جهازك يكون مفتوح.

---

## كيف تستخدمها جدتك؟

1. تبعت للبوت: `سورة البقرة 90-95`
2. البوت يعرض أزرار القراء، تختار وحد.
3. البوت يعرض أزرار عدد التكرار (1، 2، 3، 5، 7، 10)، تختار وحد.
4. البوت يبعتلها ملف صوتي (audio) جاهز.
5. تضغط زر "مشاركة" (forward) في تليجرام وترسله على واتساب لأي مجموعة.

## ملاحظات

- المصدر الصوتي: [everyayah.com](https://everyayah.com) - موقع معروف وموثوق فيه تسجيلات لكل آية بمفردها لعدد كبير من القراء.
- لو آية معينة ما نزلت (نادراً، مشكلة بالسيرفر)، البوت بيبعت التسجيل ناقص هاي الآية ويحذرك بالكابشن.
- ممكن تضيفي قراء إضافيين بالمستقبل بالتعديل على ملف `reciters.py` (لازم تعرفي اسم المجلد الصحيح من everyayah.com).
- التسجيل بيتبعت كملف mp3 (audio)، وهاد النوع أسهل شي للمشاركة على واتساب (تقدر جدتك تفوردو مباشرة).
